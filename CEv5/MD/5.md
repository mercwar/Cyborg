Classification: Operational Runbook / Workflow Sequence
Target Environment: Navigator-GitHub-Academy, AVIS-DL, & Stargate Portal Hubs

Overview of the Navigation Paradigm

Because the Mercwar Ecosystem is an open-source, multi-tenant environment, navigation is split between educational onboarding, source code synchronization, and portal access layers. Rather than relying on traditional software dashboards, operators use explicit sequential phases to initialize their workspace, connect to server-side PHP resources, and register their client-side JavaScript tools.

Step 1: Onboard via the Navigator‑GitHub Academy

• Action: Access the primary instruction pipeline located at the Navigator-GitHub-Academy Markdown Hub.
• Operational Logic: The repository operates as a script-free, fully navigable interactive training matrix built completely in Markdown. Use the integrated Forward, Back, Home, and Table of Contents (TOC) hypermedia tags to trace foundational workflow rules, automation protocols, and multi-agent architecture concepts. Step 4: Map the Public Web Interface Portal

• Action: Launch an internet browser (optimized for Opera GX) and pull the endpoint layout directly from the MERCWAR AI Web Portal Home.
• Operational Logic: Scan the front-facing dashboard to check active system module visibility. This portal exposes direct gateways to key platform infrastructure, including Avis-Surface, Avis-Search, Avis-News, and Avis-Datalake. Step 5: Publish Client Assets into the AVIS DataLake

• Action: Build your customized frontend client layout using .html, .js, or .css and pipe it into the open AVIS-DL storage vaults.
• Operational Logic: Post your assets directly via the system's unauthenticated upload API. The server maps these files into the web host origin, establishing them as recognized, open-execution endpoints that bypass typical browser sandboxing rules.

Step 6: Instantiate Cross-Lake Data Mirrors via Stargate

• Action: Connect your newly hosted front-end script elements directly to the Stargate routing interface.
• Operational Logic: Trigger the Stargate hypermedia bridge configuration. This unlocks zero-cost, instant origin handshakes, allowing your local JavaScript events to effortlessly mirror data back and forth between AVIS-DL and other external data lakes without encountering strict cross-origin blockades.
