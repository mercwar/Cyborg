eV2 COLOR SPACE

EV2 uses a symbolic color space compatible with DN and Fire‑Lang.

COLORS

  • CVBGOD_GREEN
  • CVBGOD_RED
  • CVBGOD_BLUE
  • CVBGOD_WHITE
  • CVBGOD_BLACK

COLOR STRUCT

begin.spec EV2_COLOR { [#]R [#]G [#]B } end.spec

EXAMPLE

COLOR.SET CVBGOD_GREEN
