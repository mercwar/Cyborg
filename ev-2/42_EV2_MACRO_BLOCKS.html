eV2 MACRO BLOCKS

Macro Blocks are high‑level EV2 constructs that expand into multiple IR ops.

MACRO TYPES

MACRO.EXEC
MACRO.SEED
MACRO.CDATA
MACRO.WINDOW
MACRO.FIRELINK

MACRO FORMAT

MACRO { OP1 OP2 OP3 }

EXAMPLE

MACRO EXEC_SAFE { {WISE} {EXE} }
