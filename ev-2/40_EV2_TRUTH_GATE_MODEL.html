eV2 TRUTH GATE MODEL

Truth Gates define deterministic logic conditions inside EV2.

TRUTH CONSTANTS

[#]TRUE = 0x01
[#]FALSE = 0x00
[#]UNDEF = 0xFF

TRUTH GATE SYNTAX

GATE { INPUT_A INPUT_B OUTPUT }

BUILT-IN GATES

GATE.AND
GATE.OR
GATE.XOR
GATE.NOT

EXAMPLE

GATE AND_GATE { A = [#]TRUE B = [#]FALSE OUT = [#]FALSE }
