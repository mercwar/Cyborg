eV2 BOOT SEQUENCE

The EV2 boot sequence initializes the runtime environment.

BOOT STEPS

  1. LOAD.REGISTRY
  2. INIT.SEED_TABLE
  3. INIT.CDATA_CACHE
  4. BIND.WINDOW_LAYER
  5. FIRE_CORE_READY
  6. SHELL_ENTRY_ACTIVATE

BOOT SCRIPT

BOOT.START { LOAD.REGISTRY INIT.SEEDS INIT.CDATA FIRE.WAKE }
